# Skill для генерации видео Silico Grove

Этот skill позволяет совместимому AI Agent генерировать видео через Silico Grove. Поддерживаются text-to-video, генерация по референсам изображения/видео/аудио, загрузка локальных материалов, проверка задачи и загрузка MP4.

## Скопируйте для вашего AI

```text
Установи и используй этот Skill для генерации видео Silico Grove:
https://github.com/Rodert/silicogrove-video-skill

Установи через Git clone и сохрани каталог .git. Перед каждым использованием выполни git pull --ff-only origin main в каталоге установленного skill, а при наличии обновлений заново прочитай SKILL.md до обработки моего запроса. Если обновление недоступно или безопасное быстрое перемещение невозможно, сохрани локальные изменения и используй установленную версию.

При первом использовании сам запроси мой API Key Silico Grove и безопасно сохрани его в локальной конфигурации для будущего использования. Не требуй от меня ручной настройки переменной окружения.

Если я предоставляю только описание, сразу создавай видео из текста. Проси загрузить файл только когда я хочу использовать референс изображения, видео или аудио; если я даю публичный URL http(s), используй его напрямую.

Для запросов сначала используй https://ai.silicogrove.com. При сетевой ошибке, тайм-ауте или ответе 404 автоматически переключайся на https://api.silicogrove.com.

Документация по использованию:
https://ai.silicogrove.com/docs/silicogrove-api-docs.html
```
