# مهارة Silico Grove لإنشاء الفيديو

تتيح هذه المهارة لوكيل AI متوافق إنشاء مقاطع فيديو عبر Silico Grove. وهي تدعم إنشاء الفيديو من النص، وإنشاء الفيديو باستخدام مراجع الصور أو الفيديو أو الصوت، ورفع الملفات المحلية، والتحقق من المهمة، وتنزيل MP4.

## انسخ إلى AI الخاص بك

```text
ثبّت واستخدم مهارة Silico Grove التالية لإنشاء الفيديو:
https://github.com/Rodert/silicogrove-video-skill

ثبّتها عبر Git clone واحتفظ بمجلد .git. قبل أول استخدام كل يوم، نفّذ `python3 "$SKILL_DIR/scripts/check_update.py" "$SKILL_DIR"` وأعد قراءة `SKILL.md` فقط عند ظهور `updated`. إذا تعذر التحديث أو تعذر التقديم السريع بأمان، فاحتفظ بالتعديلات المحلية واستخدم النسخة المثبتة.

عند الاستخدام الأول، اطلب مني بشكل استباقي إدخال مفتاح Silico Grove API الخاص بي واحفظه بأمان في الإعدادات المحلية لاستخدامه لاحقاً. لا تطلب مني إعداد متغير بيئة يدوياً.

إذا قدمت وصفاً للفيديو فقط، فأنشئ فيديو من النص مباشرة. اطلب مني رفع ملف فقط عندما أطلب استخدام مرجع صورة أو فيديو أو صوت؛ وإذا قدمت رابط http(s) عاماً فاستخدمه مباشرة.

استخدم أولاً https://ai.silicogrove.com للطلبات. عند حدوث خطأ في الشبكة أو انتهاء المهلة أو ظهور استجابة 404، انتقل تلقائياً إلى https://api.silicogrove.com.

وثائق الاستخدام:
https://ai.silicogrove.com/docs/silicogrove-api-docs.html
```
